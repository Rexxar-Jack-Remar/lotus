# Parser for Boolean Programs

We have a hand-written C++ version, which also supports converting the internal representation of the engine in lib/Dataflow/NPA/Domains/PredicateRelationDomain.cpp.


For further extending the parser, we may refe to the skeleton of a parser for concurrent Boolean programs in:

- Parser (bison): bp_parser.yy
- Lexer (flex): bp_scanner.ll

It is able to parse Boolean programs generated by SLAM and SatAbs.

Another choicse is to totally rely on bp_parser.yy, bp_scanner.ll, instead of using the hand-written one.
