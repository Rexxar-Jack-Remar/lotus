
# Frontend

This directory is the container for verification-language frontends.

## Boolean Program Frontend

The active implementation lives alongside this document and
contains the hand-written C++ parser plus lowering to the internal predicate
relation representation in
`lib/Dataflow/NPA/Domains/PredicateRelationDomain.cpp`.

For future parser extensions, we can also refer to the skeleton for concurrent
Boolean programs in:

- Parser (bison): bp_parser.yy
- Lexer (flex): bp_scanner.ll

These files can parse Boolean programs generated by SLAM and SatAbs.

Another option is to rely entirely on `bp_parser.yy` and `bp_scanner.ll`
instead of the hand-written parser.
