# Security Library

Security-focused analyses and transformations that target side-channel
properties and related attack surfaces.

| Subdir | Purpose |
|--------|---------|
| **ConstantTime** | CT-LLVM-based constant-time side-channel analysis. |
| **LIF** | Control-flow linearization and isochronous transformation for side-channel mitigation. |
| **Spectre** | Spectre-v1-style speculative execution and cache side-channel analysis. |
